# `bunny-gpu`

Quarantined GPU backend crate for Bunny's portable WGSL shader artifacts,
ordered golden vector fixtures, content-addressed implementation manifests, and
`wgpu` CPU-vs-GPU equivalence harnesses.

See [`docs/design/0005-gpu-compute-backend.md`](../../docs/design/0005-gpu-compute-backend.md)
and [`docs/topics/gpu-u32-div-round-even/README.md`](../../docs/topics/gpu-u32-div-round-even/README.md).
