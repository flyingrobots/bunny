# Receipt: BVH Refit

Task:
flyingrobots/bunny#120, first slice: refit. `refit_bvh(nodes, prim_indices, primitives)` gives
a built BVH new primitive boxes with its topology and primitive order unchanged: every node's
bounds become exactly the raw per-axis union of its children's (a leaf: of its listed
primitives' new boxes). One pass from the last node to the first, relying on both builders
storing children after their parent (stated and tested); no scratch, no recursion, no
allocation. A validating pass before the writing pass makes a refusal (a new
`#[non_exhaustive]` `RefitError`) write nothing. Additive: no existing public item, output
bit, golden, digest or ID changes. Dynamic update (insertion, removal, rebuild on
degradation) is not in this slice.
